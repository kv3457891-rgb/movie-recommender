# 🎬 Movie Recommendation System

A content-based movie recommendation system built using Python and Streamlit.

## 🚀 Live Demo

[Click here to use the Movie Recommendation System](https://movie-recommender-rpahbay2yn6m8r7auggl78.streamlit.app/)

## 🛠️ Technologies Used

- Python
- Pandas
- Scikit-learn
- Streamlit
- TMDB API

## ✨ Features

- Select a movie from the dropdown
- Get 5 similar movie recommendations
- Display movie posters dynamically
- TMDB API integration
- Interactive Streamlit web application

## 📌 Project Overview

This project recommends movies similar to the movie selected by the user using a content-based recommendation approach.

The application is deployed using Streamlit Cloud.
